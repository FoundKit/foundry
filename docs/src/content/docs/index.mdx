## 🌟 Core Architecture Pillars

<CardGrid>
  <Card title="Framework & Application Separation" icon="puzzle">
    Foundry is distributed as a Cargo dependency (`foundry = "0.1"`). Applications maintain their own independent Git repository with 0 upstream merge conflicts.
  </Card>
  <Card title="Self-Contained Subsystems" icon="document">
    Subsystems encapsulate custom API controllers, business services, DTO validation, and Admin UI pages in clean, cohesive modules.
  </Card>
  <Card title="Zero-DDL Dynamic Storage" icon="setting">
    Visually define system configs and dynamic data models without database DDL migrations, schema locks, or downtime.
  </Card>
  <Card title="Automatic RESTful CRUD" icon="rocket">
    Instant, high-performance REST APIs generated for all dynamic models (`GET`, `POST`, `PUT`, `DELETE`) with fine-grained access control.
  </Card>
  <Card title="Hierarchical IAM & Topic RBAC" icon="open-book">
    Super Admin (`super_admin`), Platform Admin (`admin`), and scoped Topic Admins restricted to specific subsystems (`allowed_systems`).
  </Card>
  <Card title="Unified Release Packaging" icon="laptop">
    Automated build pipeline (`build-release.sh` / Dockerfile) merging the server binary, Admin SPA, and custom pages into a single production bundle.
  </Card>
</CardGrid>
