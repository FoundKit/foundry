## 🌟 Core Architecture Pillars

<CardGrid>
  <Card title="Base & Subsystems Complete Decoupling" icon="puzzle">
    Platform infrastructure is completely decoupled from custom business subsystems. Subsystem custom code lives in a separate Git repository with zero upstream merge conflicts.
  </Card>
  <Card title="Self-Contained Subsystem Standard" icon="document">
    Each subsystem folder self-contains its custom API controllers, business services, DTO validation, custom admin pages (HTML/React), and manifest.
  </Card>
  <Card title="Zero-DDL Dynamic Storage" icon="setting">
    Visually define system configs and dynamic data models without database DDL migrations, locks, or downtime.
  </Card>
  <Card title="Automatic RESTful CRUD" icon="rocket">
    Instant, high-performance REST APIs generated for all dynamic models (`GET`, `POST`, `PUT`, `DELETE`) with fine-grained access switches.
  </Card>
  <Card title="Hierarchical IAM & Topic RBAC" icon="open-book">
    Super Admin (`super_admin`) with universal privileges, and scoped Topic Admins restricted to specific subsystems (`allowed_systems`).
  </Card>
  <Card title="Unified Release Packaging Pipeline" icon="laptop">
    Automated build pipeline (`build-release.sh` / Dockerfile) merging base infra and custom subsystems into a single production binary or container.
  </Card>
</CardGrid>
