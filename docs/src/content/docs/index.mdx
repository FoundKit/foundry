## Key Capabilities

<CardGrid stagger>
  <Card title="Multi-Tenant Sub-System Engine" icon="puzzle">
    Run independent sub-systems (apps, mini-programs, campaign backends) within a single Foundry instance with strict tenant isolation.
  </Card>
  <Card title="Zero-DDL Dynamic Storage" icon="setting">
    Define system configs and dynamic data models without database DDL migrations or metadata locks.
  </Card>
  <Card title="Automatic RESTful CRUD" icon="rocket">
    Instant REST APIs generated for all dynamic models with fine-grained access control toggles.
  </Card>
  <Card title="Decoupled Architecture" icon="laptop">
    Code-first Rust extensions, custom Admin UI pages, and standalone external repository hosting.
  </Card>
</CardGrid>
