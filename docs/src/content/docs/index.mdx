## 🌟 Core Architecture Pillars

<CardGrid stagger>
  <Card title="Multi-Tenant Sub-System Engine" icon="puzzle">
    Run $N$ independent apps, mini-programs, and campaign backends within a single unified Foundry instance with strict tenant data isolation.
  </Card>
  <Card title="Zero-DDL Dynamic Storage" icon="setting">
    Visually define system configurations and dynamic data models without database DDL migrations, locks, or downtime.
  </Card>
  <Card title="Automatic RESTful CRUD" icon="rocket">
    Instant, high-performance REST APIs generated for all dynamic models (`GET`, `POST`, `PUT`, `DELETE`) with fine-grained access switches.
  </Card>
  <Card title="Code-First Rust & WASM Extensions" icon="laptop">
    Extend subsystems with native high-performance Rust traits or sandboxed dynamic WASM plugins without restarting the server engine.
  </Card>
  <Card title="Hierarchical IAM & Topic RBAC" icon="open-book">
    Super Admin (`super_admin`) with omnipotent privileges, and scoped Topic Admins restricted to specific subsystems (`allowed_systems`).
  </Card>
  <Card title="Non-GET Operation Audit Trail" icon="warning">
    Security-first middleware capturing all state-mutating requests (POST, PUT, PATCH, DELETE, login) with full payloads and tracing metadata.
  </Card>
</CardGrid>
