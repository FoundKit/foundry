## 🌟 核心架构支柱

<CardGrid>
  <Card title="基建与子系统完全解耦" icon="puzzle">
    平台基础设施与业务子系统代码彻底物理隔离。所有子系统代码可单独存放于专属私有 Git 仓库，平台升级零代码冲突。
  </Card>
  <Card title="自包含子系统标准" icon="document">
    每个子系统目录下自包含其专属的控制器、业务服务、DTO 校验、自定义后台大屏（HTML/React）与元数据清单。
  </Card>
  <Card title="Zero-DDL 动态存储引擎" icon="setting">
    可视化定义系统参数配置与动态数据模型，无需数据库 DDL 迁移、表锁或停机维护。
  </Card>
  <Card title="自动化 RESTful CRUD" icon="rocket">
    为所有动态模型即时生成高性能 RESTful API（`GET`, `POST`, `PUT`, `DELETE`），并支持细粒度公开/鉴权开关。
  </Card>
  <Card title="分级 IAM 与 Topic 范围 RBAC" icon="open-book">
    内置超级管理员（`super_admin`）全局权限，支持为普通管理员精细化划分特定子系统管理权限（`allowed_systems`）。
  </Card>
  <Card title="一键合并打包发布流水线" icon="laptop">
    统一构建流水线（`build-release.sh` / Dockerfile），在发布打包时自动将基建与私有子系统合并为单一可执行产物。
  </Card>
</CardGrid>
