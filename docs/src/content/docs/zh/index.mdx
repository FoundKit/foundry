## 🌟 核心架构支柱

<CardGrid>
  <Card title="框架与业务完全解耦" icon="puzzle">
    Foundry 作为标准 Cargo 依赖提供 (`foundry = "0.1"`)。用户拥有独立 Git 仓库，上游框架升级零合并冲突。
  </Card>
  <Card title="高内聚业务子系统" icon="document">
    子系统封装自定义 API 控制器、业务领域服务、DTO 校验与 Admin 扩展页面，结构清晰内聚。
  </Card>
  <Card title="Zero-DDL 动态存储引擎" icon="setting">
    可视化配置系统参数与动态数据模型，无需编写数据库 DDL 迁移，避免元数据锁与停机维护。
  </Card>
  <Card title="自动生成 RESTful CRUD" icon="rocket">
    所有动态模型即刻获得开箱即用的高并发 RESTful CRUD 接口（`GET`, `POST`, `PUT`, `DELETE`）。
  </Card>
  <Card title="分级权限与专题 RBAC" icon="open-book">
    超级管理员 (`super_admin`)、普通管理员 (`admin`) 与专属专题管理员 (`topic_admin`)，支持细粒度权限控制。
  </Card>
  <Card title="统一交付与打包流水线" icon="laptop">
    自动化构建脚本 (`build-release.sh` / Dockerfile) 一键将服务二进制、Admin 前端与扩展页面打包为单一部署制品。
  </Card>
</CardGrid>
