## 🌟 核心架构支柱

<CardGrid>
  <Card title="多子系统隔离引擎" icon="puzzle">
    在单个 Foundry 统一实例中同时运行与管理多个独立业务子系统（App、小程序、营销活动后端），保持严格的数据与租户隔离。
  </Card>
  <Card title="Zero-DDL 动态存储引擎" icon="setting">
    可视化定义系统参数配置与动态数据模型，无需数据库 DDL 迁移、表锁或停机维护。
  </Card>
  <Card title="自动化 RESTful CRUD" icon="rocket">
    为所有动态模型即时生成高性能 RESTful API（`GET`, `POST`, `PUT`, `DELETE`），并支持细粒度公开/鉴权开关。
  </Card>
  <Card title="Code-First Rust 与 WASM 扩展" icon="laptop">
    通过原生 Rust Trait 实现极致业务性能，或通过沙箱化 WASM 插件实现零停机动态热加载。
  </Card>
  <Card title="分级 IAM 与 Topic 范围 RBAC" icon="open-book">
    内置超级管理员（`super_admin`）全局权限，支持为普通管理员精细化划分特定子系统管理权限（`allowed_systems`）。
  </Card>
  <Card title="非 GET 写操作全量审计追踪" icon="warning">
    安全第一的中间件体系，自动捕获所有写操作（POST、PUT、PATCH、DELETE、登录）的完整载荷与链路追踪信息。
  </Card>
</CardGrid>
